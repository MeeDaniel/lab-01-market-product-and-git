## Product Choice
- **Product name**: Telegram
- **Product link**: https://telegram.org/
- **Description**: The most popular social network in Russia.

## Main Components
![Telegram Component Diagram](../docs/diagrams/out/telegram/component-diagram/Component%20Diagram.svg)

- **Mobile app**: Program of this social network that works on mobile phones.
- **Desktop app**: Program of this social network which that works on computers.
- **Web client**: Web-site for every person who has no mobile app or desktop app. Program that works in browsers.
- **Message handling service**: getting messages from users and sending it to others
- **Auth & Session service**: processes logging in and logging out in different devices.
